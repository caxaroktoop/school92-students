ШКОЛА №92 — Sakura v5

Что исправлено:
- При регистрации роль всегда «Ученик».
- «Старшеклассник», «Модератор» и «Администратор» назначаются только владельцем.
- Обычный ученик не может передать роль через регистрацию или обычный API.
- Добавлена защищённая авторизация по сессионному токену.
- Исправлено сохранение аккаунта: имя и аватар можно менять, роль при этом сохраняется.
- Чат работает через авторизованный аккаунт.
- Модераторы и администратор видят раздел жалоб и могут скрывать/оставлять сообщения.
- Администратор назначается владельцем через OWNER_KEY.

Запуск:
1) npm install
2) Задай секрет владельца:
   export OWNER_KEY="придумай-длинный-секрет"
3) npm start
4) Открой http://localhost:3000

Назначение роли владельцем через API:
POST /api/admin/users/ID/role
Заголовок: x-owner-key: ТВОЙ_OWNER_KEY
JSON: {"role":"Модератор"}

Допустимые роли:
Ученик
Старшеклассник
Модератор
Администратор

Важно: это всё ещё учебный MVP. Для публичного запуска нужны HTTPS, нормальная база данных, резервные копии, rate limiting, CSRF-защита и полноценная система авторизации владельца/модераторов.
